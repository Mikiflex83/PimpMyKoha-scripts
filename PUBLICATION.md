# Publication sur GitHub

Créer le nouveau dépôt, puis y déposer le contenu de ce dossier : `README.md`, `PUBLICATION.md`, `.gitignore` et `scripts/`. Ne pas déposer le ZIP d’origine, qui contient les paramètres de l’installation.

Cette copie conserve les fichiers et les fonctions des scripts ; seuls les paramètres Firebase identifiés, les adresses nominatives, les mots de passe locaux repérés et les domaines internes ont été remplacés. Aucun badge de préparation au plugin n’a été ajouté.

Le chargeur de production n’est pas distribué comme chargeur générique : 14 de ses appels actifs ne correspondent pas à des fichiers présents dans le ZIP reçu. Il ne faut pas le recopier tel quel pour une autre installation. Ces écarts n’empêchent pas de publier les sources pour les consulter.

La licence reste à choisir. Les réglages et données réelles doivent rester hors du dépôt lors des mises à jour.
